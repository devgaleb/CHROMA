# Contributing to CHROMA

Open a focused issue describing the problem, your OS/Python version, input media properties, expected output and actual result. Remove sensitive footage or obtain permission before sharing samples.

For code changes: create a branch, keep commits focused, add or update tests, run `python -m unittest discover -s tests -v`, and document changes to the UI or processing pipeline. Do not submit pretrained model weights or footage without redistribution rights. Preserve third-party licence files. Pull requests should describe how the change was verified and any known limitations.
